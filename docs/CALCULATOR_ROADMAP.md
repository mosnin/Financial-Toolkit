### Prioritization Criteria

1. **Search volume**: Higher volume keywords are prioritized.
2. **Competition gap**: Calculators where existing tools are outdated or poorly designed.
3. **Category completeness**: Filling out a category to 8+ calculators strengthens topical authority.
4. **Cross-link potential**: Calculators that naturally link to many existing pages.
5. **Monetization potential**: Calculators that align with affiliate or lead-gen opportunities.

## 6. Monetization Roadmap

### Phase 1: Foundation (Months 1-6)

- No monetization. Focus entirely on traffic growth and SEO authority.
- Build email list with optional "Save your calculation" feature.

### Phase 2: Affiliate Revenue (Months 6-12)

- **Mortgage affiliate links**: Partner with mortgage comparison platforms (e.g., LendingTree, Bankrate).
- **Credit card affiliate links**: On credit card payoff and debt calculators.
- **Investment platform referrals**: On retirement and investment calculators.
- All affiliate links clearly disclosed. No impact on calculator accuracy.

### Phase 3: Premium Features (Months 12-18)

- **Save and compare**: User accounts to save calculations and compare scenarios.
- **PDF reports**: Export detailed calculation reports as branded PDFs.
- **Embeddable widgets**: White-label calculator widgets for blogs, real estate sites, and financial advisors.
- Pricing: Free tier (basic calculators) + Pro tier ($5-10/month for saves, exports, embeds).

### Phase 4: B2B and API (Months 18+)

- **Calculator API**: REST API for developers to integrate CalcWise calculations.
- **White-label solutions**: Custom-branded calculator suites for banks, lenders, and financial advisors.
- **Lead generation**: Optional lead capture for mortgage, insurance, and loan calculators (user opt-in only).
- **Sponsored calculators**: Financial institutions sponsor specific calculators with their branding (clearly labeled).

## 7. Quality Standards for All New Calculators

Every new calculator must meet these criteria before launch:

- [ ] Accurate formula implementation verified against 3+ external sources
- [ ] Edge case handling (zero values, negative numbers, extremely large numbers)
- [ ] Mobile responsive design tested at 320px, 375px, 768px, 1024px, 1440px
- [ ] Full page content (1,200+ words) following `CONTENT_TEMPLATE.md`
- [ ] JSON-LD schema validated via Google Rich Results Test
- [ ] Lighthouse score 95+ across all four categories
- [ ] Added to sitemap.xml
- [ ] Linked from category hub and 2+ sibling calculators
- [ ] Cross-linked from at least 1 calculator in another category (where relevant)
- [ ] Disclaimer present
