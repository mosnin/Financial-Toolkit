Annualized Return Formula

The annualized return formula uses the geometric mean to express investment performance as a consistent yearly rate:

Annualized Return Formula
Annualized Return = (Ending Value / Beginning Value)^(1 / Years) - 1

The total return measures overall growth without adjusting for time:

Total Return Formula
Total Return = (Ending Value - Beginning Value) / Beginning Value × 100

How to Use This Annualized Return Calculator

  1. Enter the beginning value — the amount invested or the starting portfolio value.
  2. Enter the ending value — the current or final value of the investment.
  3. Enter the years held — the number of years between the start and end dates (decimals are accepted).
  4. Click "Calculate Return" to see your annualized return, total return, and dollar gain or loss.

Example Scenario

Suppose you invested $10,000 and your portfolio grew to $18,000 over 5 years. The total return would be 80%, but the annualized return would be approximately 12.47% per year. This means your investment compounded at roughly 12.47% each year to reach that final value, and your dollar gain was $8,000.
